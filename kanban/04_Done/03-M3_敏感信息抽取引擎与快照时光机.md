# M3 - 敏感信息抽取引擎与快照时光机

### 📌 任务目标
构建端侧轻量混合抽取系统（高精度正则 + 端侧 LLM 上下文感知），支持长文档分块滑动窗口（Overlap）与跨块幂等消解，建立以 `priority`（高/中/低）为核心的统一数据契约，并实现包含已检出/未检出闭环的历史快照时光机持久化存储。

### 📋 子任务清单 (Checklist)
- [x] 正则引擎与端侧 LLM 混合抽取流水线构建
- [x] 长文本分块滑动窗口（Overlap Chunking）与跨分块重叠去重
- [x] 端侧小模型（450M~1.5B）指令隔离、防漂移提示词模板矩阵
- [x] 提示词字段权重与行内 `(优先级: 高/中/低)` 动态注入
- [x] 历史快照版本控制中心与时光机落盘机制（`.sensidoc_workspace.json`）
- [x] 全系统数据契约重构：彻底淘汰 `risk_level`，确立纯 `priority` 架构
- [x] 闭环审计设计：同时追踪 `detected_items`（已检出）与 `missed_fields`（未检出）
