# M5 - 全格式纯代码原生版式脱敏导出引擎

### 📌 任务目标
实现 SensiDoc v2 核心脱敏导出引擎，支持跨 XML 节点文字合并替换与 PDF 字符流精确抹除，在完全保留原文档排版、样式、表格、图片等布局的前提下，完成 DOCX/XLSX/PPTX/PDF/TXT/CSV 的全格式纯代码原生脱敏导出。

### 📋 子任务清单 (Checklist)
- [x] 编制并确立 `IMPLEMENTATION_PLAN_v2.md` 实施方案
- [x] 原生 DOCX XML 跨 `<w:t>` 节点 Unicode 字符投影合并与精确回写打码
- [x] 原生 XLSX 共享字符串池（`sharedStrings.xml`）与单元格段落打码
- [x] 原生 PPTX 幻灯片文本框段落脱敏与 ZIP 内存流重构
- [x] 纯 Rust 原生 PDF Content Stream 算子解析（`Tj`/`TJ`）与多编码抹除（`lopdf`）
